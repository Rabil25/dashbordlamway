⚙ Konfigurasi GAS URL
Masukkan URL Web App Google Apps Script yang sudah di-deploy. Tidak perlu API Key.
Cara deploy GAS:
1. Buka Google Sheets → Extensions → Apps Script
2. Paste isi file gas/Code.gs
3. Deploy → New deployment → Web App
4. Execute as: Me · Who can access: Anyone
5. Copy URL, paste di sini
